# Game Management

نظام إدارة يومي لمحل ألعاب وتسلية (بلايستيشن، بلياردو، وبينغ بونغ) مع إدارة ورديات، جلسات تشغيل، مشروبات، ومصاريف — مبني ليعمل بسرعة على الكمبيوتر والموبايل.

## التقنيات

- Next.js 16 + React 19 + TypeScript
- Tailwind CSS v4
- Supabase: PostgreSQL + Auth
- Vercel للنشر

## البداية محليًا

1. انسخ `.env.local.example` إلى `.env.local` وأضف مفاتيح مشروع Supabase.
2. نفّذ migrations Supabase.
3. `npm install`
4. `npm run dev`
5. افتح `http://localhost:3000`
